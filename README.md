# GuruHat Scoop bucket

Free, open-source Windows apps from [GuruHat](https://guruhat.com), installable with [Scoop](https://scoop.sh).

```powershell
scoop bucket add guruhat https://github.com/getguruhat/scoop-bucket
scoop install guruhat/ai-meter   # Claude Code / Codex usage on the taskbar
```

- **AI Meter:** [getguruhat/ai-meter](https://github.com/getguruhat/ai-meter)
